# TaskFlow API

TaskFlow, görev oluşturma, listeleme, güncelleme ve silme işlemlerini gerçekleştirmek amacıyla geliştirilen bir RESTful Web API projesidir.

## Technologies

- C#
- .NET 10
- ASP.NET Core Web API
- Swagger / OpenAPI
- Git & GitHub

## Project Status

The project is under active development.

Current stage:

- ASP.NET Core Web API project setup
- Controller-based API structure
- Swagger UI integration

## Getting Started

### Requirements

- .NET 10 SDK
- Visual Studio 2026 or another compatible IDE

### Run the Project

```bash
dotnet restore
dotnet run
```

After running the project, Swagger UI can be accessed from:

```text
https://localhost:<port>/swagger
```
